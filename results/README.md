# Result files

The stable result files are regenerated by `scripts/build_results.R`.

- `season_results.csv`: selected Dummy RAPM and no-dummy test metrics by season.
- `model_summary.csv`: mean RMSE and R-squared by model.
- `paired_results.csv`: season-level RMSE and R-squared differences.
- `paired_summary.csv`: paired tests and confidence intervals for the primary comparison.
- `selected_configuration.csv`: derived threshold, penalty, and checked bounds.
- `penalty_tuning.csv`: inner-validation penalty search from 1.0 through 2.5,
  including any automatic boundary extensions.
- `model_grid.csv`: complete broad threshold and penalty grid.
- `selected_coefficients.csv`: selected player and dummy coefficients.
- `dummy_coefficient_summary.csv`: descriptive cross-season dummy summaries.
- `sample_summary.csv`: included games, exclusions, stints, and players by season.
- `selected_category_exposure_by_season.csv`: selected outer-training
  side/count exposure by season.
- `dummy_category_exposure.csv`: selected side/count stint and possession
  exposure aggregated across seasons.
- `starter_exclusions.csv`: games excluded for incomplete starter metadata.
- `sensitivity_summary.csv`: zero-threshold and 2019-exclusion comparisons.
- `intermediate/`: pipeline outputs used to construct the stable tables.
